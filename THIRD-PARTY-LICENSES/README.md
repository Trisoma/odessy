# Retained license texts

The existing OpenClaw, NemoClaw and DeepSeek Harness texts retain their original
attribution. Additional upstream texts downloaded October 23, 2026:

| Local file | Upstream source |
|---|---|
| Whisper-MIT.txt | https://raw.githubusercontent.com/openai/whisper/main/LICENSE |
| Whisper-cpp-MIT.txt | https://raw.githubusercontent.com/ggml-org/whisper.cpp/master/LICENSE |
| Kokoro-ONNX-MIT.txt | https://raw.githubusercontent.com/thewh1teagle/kokoro-onnx/main/LICENSE |
| Silero-VAD-MIT.txt | https://raw.githubusercontent.com/snakers4/silero-vad/master/LICENSE |
| GPL-3.0.txt | https://raw.githubusercontent.com/bootphon/phonemizer/master/LICENSE |
| CC-BY-NC-SA-4.0.txt | https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.txt |

The generic Apache-2.0 text is also present in the repository's root `LICENSE`;
upstream component-specific notices still need preservation. A GPL license text
alone does not fulfill all source/distribution obligations. The CC license text
alone does not supply model attribution: see the openWakeWord/Jarvis source and
asset details in the [inventory](../docs/reference/third-party-licenses.md).

These are reference copies from upstream at the review date, not proof of the
exact revision of an independently installed executable or downloaded model.
Preserve the exact versions' own LICENSE/NOTICE files when assembling a bundle.
