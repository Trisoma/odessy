## Benchmark Evidence

Command family:

```bash

python -m benchmark --manifest benchmark/profiles.toml ...
```

Warm results from `benchmark/results/20260911-145646`:

| Profile | Success | P50 inference | P95 inference | Mean RTF |

| Profile | Success | P50 total | P50 inference | P50 initialization |
| --- | ---: | ---: | ---: | ---: |
| `kokoro_pytorch_cold` | 5/5 | 4966.34 ms | 548.72 ms | 4423.99 ms |

| `onnx_cuda_cold` | 5/5 | 6770.30 ms | 4317.91 ms | 2459.83 ms |

The PyTorch warm path is approximately 8.2 times faster than either ONNX
path for this text. The PyTorch path generated approximately 3.1 seconds of
audio, while the ONNX paths generated approximately 2.45 seconds, so the
result is a strong runtime signal but not a fully controlled voice/model
comparison yet.

## Decision

Use local PyTorch Kokoro CUDA as the current primary low-latency TTS candidate.
Keep ONNX CPU and ONNX CUDA as baselines. Keep TensorRT experimental and do
not describe it as a measured Kokoro backend until it completes a valid run.
