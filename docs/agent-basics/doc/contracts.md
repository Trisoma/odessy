Durable conversation_id/project_id are server UUID hex, stable across restart. Project metadata is not workspace authority. Ordinary history browsing never creates a runtime. 06 migrates process-bound desktop grouping to durable project IDs explicitly.

Bearer never in URLs/data/logs; use existing redaction before persistence/export. Workers don't put raw secret-bearing approval details in DB.
