## Limits and policy (also in docs/ui/context-memory-retrieval.md)

* Context: 24,000 chars default including wrapper labels; 3 recent completed turns; summary 2,000 chars; facts ≤100 items × 2,000 chars; citations ≤5; invalid/oversized/malformed input fails closed.
* Memory: ≤500 facts/project, ≤100 injected; project isolation on every read/write.
* Documents: 256 KiB/file, 100 files and 10 MiB text/project, chunks ~2,000/200, query ≤512 chars, top-k 1–10.
* Refused at ingestion: absolute/escape paths, control characters, sensitive directories/files, non-allowed extensions, binary content, oversize, project-limit overflow. Retrieval re-checks project scope and only returns `ready` documents.
* Context composition never includes tool calls/results, approvals, grants, activity text or attachments; only user/assistant public text, summary, explicit facts and cited chunks.
